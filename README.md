# DSA in 90 Days

A structured 90-day journey to revise and learn Data Structures and Algorithms using TypeScript.

## Overview

This repository contains daily DSA problems, concepts, and implementations organized by day. Each day focuses on a specific topic or problem type, building up from fundamentals to advanced concepts.

## Structure

| Days | Topic |
|------|-------|
| 1–10 | Basics: Arrays, Strings, Hashing |
| 11–20 | Sorting & Searching |
| 21–30 | Linked Lists, Stacks, Queues |
| 31–45 | Trees & Binary Search Trees |
| 46–55 | Heaps, Priority Queues |
| 56–65 | Graphs (BFS, DFS) |
| 66–75 | Dynamic Programming |
| 76–85 | Backtracking, Greedy |
| 86–90 | Mock Interviews & Review |

## Running Solutions

All solutions are written in TypeScript.

```bash
# Run a specific day's solution
npx ts-node day-<N>-<topic>.ts
```
